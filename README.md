## 每站五页一组

1. **快速入口** — 这站讲什么、从哪进、和前后站怎么衔接
2. **图解讲义** — 每个考点配图示，图形均为代码绘制
3. **分层练习** — A/B/C 三层，附限时建议
4. **答案与详解** — 全部展开推导，含易错对照
5. **闭卷检索与回炉** — 合上资料自检，漏了哪条回哪节

## 特性

- 纯静态 HTML，无构建、无依赖、无外部请求；公式全部内联渲染，下载整个文件夹离线同样可读
- 页面内的学习进度保存在你自己的浏览器 localStorage，不会上传
- 数学推导逐条复核（sympy 精确复算），发现错误欢迎提 Issue
