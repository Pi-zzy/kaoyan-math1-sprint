§0 一句话抓住本站

P02–P04 给了"单个/两个变量"的分布与数字特征；本站回答两个大量重复才出现的问题：

§1 依概率收敛（一切"稳定性"的数学语言）

人话定义

nnn 次试验里的量 XnX_nXn​（比如 nnn 次抛硬币的正面频率），随着 nnn 增大越来越贴近常数 aaa——但不是"必然贴近"，而是"贴近的概率越来越大"。

严格定义（两种写法，考场写极限式）

lim⁡n→∞P{∣Xn−a∣≥ε}=0(∀ε>0)\lim_{n\to\infty}P\big\{|X_n-a|\ge\varepsilon\big\}=0\qquad(\forall\varepsilon>0)n→∞lim​P{∣Xn​−a∣≥ε}=0(∀ε>0)

记作 Xn→PaX_n\xrightarrow{P}aXn​P​a，读"XnX_nXn​ 依概率收敛于 aaa"。

ε\varepsilonε–NNN 语言版：对任意 ε>0\varepsilon>0ε>0 和任意 η>0\eta>0η>0，存在 NNN，当 n>Nn>Nn>N 时恒有

P{∣Xn−a∣≥ε}<η.P\big\{|X_n-a|\ge\varepsilon\big\}<\eta .P{∣Xn​−a∣≥ε}<η.

两个自由度各管一摊：ε\varepsilonε 管"带多窄"，η\etaη 管"跳出带多罕见"。注意极限写的是概率 →0\to0→0，不是 ∣Xn−a∣→0|X_n-a|\to0∣Xn​−a∣→0。

与数列（逐点）收敛的区别（一句话）

数列 an→aa_n\to aan​→a：NNN 一旦定下，之后每一次都满足 ∣an−a∣<ε|a_n-a|<\varepsilon∣an​−a∣<ε，一劳永逸；依概率收敛：允许偶尔跳出带外，只是跳出这件事的概率随 nnn 增大趋于零。所以"依概率收敛"比"必然收敛"松——它管的是概率不是命运。

最小例子：Xn∼U(0,1n)X_n\sim U(0,\tfrac1n)Xn​∼U(0,n1​)。对任意固定 ε>0\varepsilon>0ε>0，P{∣Xn∣≥ε}=max⁡(1−nε,0)→0P\{|X_n|\ge\varepsilon\}=\max(1-n\varepsilon,0)\to0P{∣Xn​∣≥ε}=max(1−nε,0)→0，所以 Xn→P0X_n\xrightarrow{P}0Xn​P​0。有限 nnn 且带宽 ε<1/n\varepsilon<1/nε<1/n 时，跳出概率为 1−nε>01-n\varepsilon>01−nε>0；但固定 ε\varepsilonε 后，足够大 nnn 的跳出概率已经是零，不能说本例“永远可能跳出同一条带”。均匀连续分布的单点 1/n1/n1/n 概率为零，应以区间事件说明非零取值。练习 A1 把这笔账算全。

依概率收敛 vs 依分布收敛（一句话 + 一个例）

  • 依分布收敛 Xn→dXX_n\xrightarrow{d}XXn​d​X：FXn(x)→FX(x)F_{X_n}(x)\to F_X(x)FXn​​(x)→FX​(x)（在 FXF_XFX​ 的连续点）。它只说分布形状趋于某个分布，不管变量本身稳定不稳定。
  • 一句话区别：本章 LLN 通常依概率收敛到常数；一般的依概率收敛也允许随机变量作为极限，定义看 P{∣Xn−X∣≥ε}→0P\{|X_n-X|\ge\varepsilon\}\to0P{∣Xn​−X∣≥ε}→0。依分布收敛只管分布函数，不能单凭它推出与某个随机变量的距离概率趋零。

例：取定 Z∼N(0,1)Z\sim N(0,1)Z∼N(0,1)，令 Xn=(−1)nZX_n=(-1)^nZXn​=(−1)nZ。每个 XnX_nXn​ 的分布都是 N(0,1)N(0,1)N(0,1)，所以 FXn(x)≡Φ(x)F_{X_n}(x)\equiv\Phi(x)FXn​​(x)≡Φ(x)——当然依分布收敛到 N(0,1)N(0,1)N(0,1)；但 XnX_nXn​ 在 ZZZ 和 −Z-Z−Z 之间来回蹦，对任意常数 aaa，P{∣Xn−a∣≥ε}P\{|X_n-a|\ge\varepsilon\}P{∣Xn​−a∣≥ε} 不趋于 0——不依概率收敛到任何常数。完整证明见练习 C6。

本站坐标：伯努利大数定律说频率 →Pp\to^{P}p→Pp（依概率）；中心极限定理说 X−npnp(1−p)→dN(0,1)\dfrac{X-np}{\sqrt{np(1-p)}}\xrightarrow{d}N(0,1)np(1−p)​X−np​d​N(0,1)（依分布）——后者不能写成"依概率收敛到 N(0,1)N(0,1)N(0,1)"（练习 B6(3) 专治）。

§2 切比雪夫不等式（正式证明 + 两种用法）

P04 §3 已用"平方 + Markov"给过两行速证；这里按教材正式写法完整展开（离散/连续通用，二阶矩存在是唯一门槛）。

定理（切比雪夫不等式）

设 E(X)=μE(X)=\muE(X)=μ，D(X)=σ2D(X)=\sigma^2D(X)=σ2 存在，则对任意 ε>0\varepsilon>0ε>0：

P{∣X−μ∣≥ε} ≤ σ2ε2等价地P{∣X−μ∣<ε} ≥ 1−σ2ε2.P\big\{|X-\mu|\ge\varepsilon\big\}\ \le\ \frac{\sigma^2}{\varepsilon^2}\qquad\text{等价地}\qquad P\big\{|X-\mu|<\varepsilon\big\}\ \ge\ 1-\frac{\sigma^2}{\varepsilon^2}.P{∣X−μ∣≥ε} ≤ ε2σ2​等价地P{∣X−μ∣<ε} ≥ 1−ε2σ2​.

正式证明（一行一步，"分段放大"版）

第0步 条件行：E(X)=μ、D(X)=σ² 存在（二阶矩存在即可，分布形状不需要知道）
第1步 只看"偏离 ≥ ε"那段对 E[(X-μ)²] 的贡献（连续型；离散把 ∫ 换成 Σ）：
      σ² = ∫_{-∞}^{+∞} (x-μ)² f(x) dx ≥ ∫_{|x-μ|≥ε} (x-μ)² f(x) dx
      ← 扔掉了 |x-μ|<ε 那一段，被积函数非负，所以积分只会变小
第2步 在剩下的区域内 |x-μ| ≥ ε，故 (x-μ)² ≥ ε²，可以再放大：
      ∫_{|x-μ|≥ε} (x-μ)² f(x) dx ≥ ε² ∫_{|x-μ|≥ε} f(x) dx = ε²·P{|X-μ| ≥ ε}
      ← 把"变化的平方"统一换成"最小的平方 ε²"，剩下的 ∫f 恰好是概率
第3步 两条不等式串起来：σ² ≥ ε²·P{|X-μ| ≥ ε}
第4步 两边除以 ε²>0，移项即得结论。
      （P04 §3 的 Markov 速证：{ |X-μ|≥ε } = { (X-μ)² ≥ ε² }，对非负随机变量
        (X-μ)² 用 Markov：P{Z≥a} ≤ E(Z)/a，一步到 P{…} ≤ σ²/ε² —— 两法同源。）

直觉：σ2\sigma^2σ2 是"平均平方离差"这个总预算；单笔开销（跳到带外 ε\varepsilonε 之外）至少要 ε2\varepsilon^2ε2，所以预算 σ2\sigma^2σ2 最多支撑 σ2/ε2\sigma^2/\varepsilon^2σ2/ε2 次概率。方差越小、带越宽，跳出越难。

为什么有用：它不需要知道分布——只凭 EEE 和 DDD 就能给概率一个保底估计。这正是大数定律全部证明的发动机（§3 三步走只靠它）。

用法一：估概率界（分布未知时给保底）

模板：

第1步 把事件 |X-μ|≥ε 凑成切比雪夫的标准形（中心对齐 μ，宽度是 ε）
第2步 写界 σ²/ε²；若事件是 <|·|<ε 型，取对立后写 1-σ²/ε²
第3步 条件行：只用了 E、D 存在——这是"最坏情形保证"，不是近似值

（数一旁注：由这个界可以引出实际推断原理——概率很小的事件在一次试验中几乎不发生；"很小"没有官方分界线，是经验口径。）

用法二：反推 n（要多少样本才够）

对 nnn 个独立同分布 XiX_iXi​（E=μE=\muE=μ，D=σ2D=\sigma^2D=σ2）的算术平均 Xˉn=1n∑Xi\bar X_n=\frac1n\sum X_iXˉn​=n1​∑Xi​：

第1步 E(X̄) = μ（期望线性），D(X̄) = σ²/n（独立可加再除 n²）—— 写全这两行
第2步 切比雪夫：P{|X̄-μ| ≥ ε} ≤ σ²/(nε²)
第3步 要求 1-σ²/(nε²) ≥ 1-δ ⟺ σ²/(nε²) ≤ δ ⟺ n ≥ σ²/(δε²)

例1（基础 · 切比雪夫两种用法连做：估界 + 反推 n，自编）

某量 XXX 分布未知，只知 E(X)=2E(X)=2E(X)=2，D(X)=1D(X)=1D(X)=1。
(1) 估计 P{0<X<4}P\{0<X<4\}P{0<X<4} 的下界；(2) 另取独立同分布的 X1,…,XnX_1,\dots,X_nX1​,…,Xn​（与 XXX 同分布），问 nnn 至少多大才能保证 P{∣Xˉ−2∣<0.5}≥0.95P\{|\bar X-2|<0.5\}\ge0.95P{∣Xˉ−2∣<0.5}≥0.95（用切比雪夫）。

(1) 第1步 凑标准形：{0<X<4} = {|X-2|<2}   ← 中心 2 = E(X)，宽度 2，对齐！
    第2步 套下界形式：P{|X-2|<2} ≥ 1 - D(X)/2² = 1 - 1/4 = 3/4
    答案：P{0<X<4} ≥ 3/4（对一切方差为 1、期望为 2 的分布都成立）
(2) 第1步 E(X̄)=2，D(X̄)=1/n   ← 独立同分布，方差可加再除 n²

易错点：①事件不对称于 μ\muμ 时，求下界应找包含于目标事件的中心对称小区间。例如 {1<X<3}⊂{1<X<4}\{1<X<3\}\subset\{1<X<4\}{1<X<3}⊂{1<X<4}，可对前者套切比雪夫（本例只得平凡下界零）；不能把较大事件 {0<X<4}\{0<X<4\}{0<X<4} 的下界移给较小事件。②反推 nnn 时 D(Xˉ)D(\bar X)D(Xˉ) 忘除 nnn，或把充分样本量说成真实最小值。

迁移信号：见"分布未知 + 估概率/定样本量"→ 切比雪夫；见 Xˉ\bar XXˉ → 先写 E(Xˉ)=μE(\bar X)=\muE(Xˉ)=μ、D(Xˉ)=σ2/nD(\bar X)=\sigma^2/nD(Xˉ)=σ2/n 两行再动手。

§3 大数定律三兄弟：切比雪夫、辛钦、伯努利

问题与结论模板

三个定律回答平均或频率何时稳定；期望不同时须使用中心化平均。下面三步证明适用于切比雪夫与伯努利大数定律；辛钦允许方差无穷，不能把同一方差证明套过去：

第1步 算 E(X̄) 与 D(X̄)（或频率的）
第2步 用切比雪夫不等式写出 P{|X̄-μ| ≥ ε} 的上界
第3步 令 n→∞，上界 →0 ⟹ 依概率收敛

切比雪夫大数定律的证明（三步走现场示范）

第1步 记 X̄=(1/n)ΣX_i，μ̄=(1/n)Σμ_i。E(X̄)=μ̄；
      D(X̄) = (1/n²)ΣD(X_i) ≤ (1/n²)·nC = C/n   ← 独立(两两不相关)保证方差可加，一致有界保证收敛
第2步 切比雪夫：P{|X̄-μ̄| ≥ ε} ≤ D(X̄)/ε² ≤ C/(nε²)
第3步 n→∞ 时 C/(nε²)→0 ⟹ P{|X̄-μ̄| ≥ ε}→0，即 (1/n)Σ(X_i-μ_i) →P 0
      若所有 μ_i=μ，则 μ̄=μ，即 X̄ →P μ。∎

辛钦大数定律（条件、结论、为什么方差不需要）

  • 条件：X1,X2,…X_1,X_2,\dotsX1​,X2​,… 独立同分布，且 E(Xi)=μE(X_i)=\muE(Xi​)=μ 存在（E∣X∣<∞E|X|<\inftyE∣X∣<∞）。
  • 结论：Xˉn→Pμ\bar X_n\xrightarrow{P}\muXˉn​P​μ。
  • 为什么方差都不需要：收敛的速度由分布尾部控制，只要均值存在，尾部"平均而言"可控；特征函数法绕开了方差。考研不要求会证，但必须会判条件——见到"独立同分布 + 期望存在"就敢用辛钦。
  • 反例对照：柯西分布连期望都没有，辛钦的门槛过不去。独立同柯西样本的均值仍服从同一个柯西分布，不依概率趋任何常数；分布不变本身却仍有依分布收敛，不能笼统说“永远不收敛”。
