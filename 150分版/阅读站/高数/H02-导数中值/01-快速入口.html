四、第一步模板（三句背下来）

  1. 求极值：写定义域 → 候选点清单（驻点 + 不可导点）→ 列表 → 报数值。
  2. 证存在 ξ：把目标式认成"某函数的导数为零"（构造表）→ 写构造 → 逐条核对定理条件 → 收尾"因子非零"。
  3. 数根/含参：切单调段 → 每段"两端异号 ⇒ 有且只有一根" → 极值值符号是分类总开关。

五、常见事故对照（快速排雷）

  • 驻点当极值（x3x^3x3 反例）→ 变号才算（图 3，§2.4）。
  • 候选漏不可导点、或把定义域外的点算候选（x+1xx+\frac1xx+x1​ 的 x=0x=0x=0）→ §2.2、A1。
  • f′′=0f''=0f′′=0 就报拐点（x4x^{4}x4 反例）→ 变号才算 + 报坐标（§4.2、A2）。
  • 罗尔三条件漏核、柯西 g′≠0g'\neq0g′=0 不写 → 大题步骤分主要扣点（§6.6、A4、C4）。
  • 端点当极值点报"极大/极小"→ 端点只谈最值（B3）。
  • 求出的 ξ\xiξ 不验范围（A5、B6）→ "解出 ξ → 验区间"两连步。
  • 皮亚诺余项当区间误差界 → 证明/误差用拉格朗日余项（§6.5、C3）。
  • 双中值题把 ξ,η\xi,\etaξ,η 当同一个点 → 各找各的（C8）。
  • 算完不验算 → 本站例题/详解每题示范第二路线，照抄这个习惯。
