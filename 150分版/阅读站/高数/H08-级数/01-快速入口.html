四、「第一步」模板（背下来，考场上直接写）

判敛题第一步三连：

① 通项极限 ≠ 0 或不存在？ → 写"由必要条件，发散"收工。
② 变号？ → 先写 Σ|uₙ| 的判别（比值/比较/根值/积分之一 + 定理名）。
③ 绝对值发散但原级数交错？ → 莱布尼茨两条件逐条核（单调 + →0），
   两条件都不满足才考虑配对/拆项。结论必须落到三态之一。

幂级数题第一步两连：

① 认形状：完整系数列 → R = lim|aₙ/aₙ₊₁|；缺项 → 通项比值解 x 范围。
② 端点逐个代入：得到的是数项级数，用判敛工具判开/闭；写"收敛域"三件套：
   区间 + 左端点结论 + 右端点结论。

和函数/展开题第一步：

先写收敛域 → 区间内逐项求导或积分 → 积分必补常数并用 x=0（或已知点）定值
→ 端点单独验证能否延拓 → 最终答案带域。

傅里叶题第一步：

① 奇偶判定（奇 → 只算 bₙ；偶 → 只算 aₙ）。
② 写对参数：周期 2π 用 cos nx；周期 2l 用 cos(nπx/l)，系数前乘 1/l。
③ 问点值前先分类：连续点 / 间断点（平均值）/ 周期端点（平均值）。

五、本站三条红线（出错即重灾区）

  1. ρ 与 1 的比较方向必须显式写出（旧材料曾把 2/e≈0.7362/e\approx0.7362/e≈0.736 说成 >1>1>1 误判发散）——算出 ρ 先写数值、再写不等号方向、再下结论；ρ=1 判别法失效换法。
  2. 幂级数收敛域端点必须单查——只写区间丢一半分。
  3. 判敛结论必须落到三态（发散/条件收敛/绝对收敛），傅里叶间断点取左右极限平均值。
