四、识别信号速查

  • 点积 =0=0=0 → 垂直；叉积 =0=0=0 → 平行；混合积 =0=0=0 → 共面。
  • 分母 0 的对称式 → 该分量为 0（不是无意义）。
  • 方程缺变量 → 柱面（母线平行该轴）。
  • 方程有一次变量 → 抛物面家族；全正 → 椭球；一负 → 单叶；两负 → 双叶；右端 0 且平方对面 → 锥面。
  • z=xyz=xyz=xy 型（无平方项）→ 45° 代换后仍是马鞍面（B4②）。
  • 开根打包后出现 (⋯ )2=(⋯ )2(\cdots)^2=(\cdots)^2(⋯)2=(⋯)2 平方再平方 → 不一定是二次曲面（C5 轮胎面）。
